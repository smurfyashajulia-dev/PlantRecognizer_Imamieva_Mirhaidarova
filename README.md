# Plant Recognizer – Распознавание растений 


## Основные возможности

- Загрузка фото с **камеры** или из **галереи**
- Классификация изображения нейросетью прямо на телефоне (оффлайн)
- Вывод **трёх** самых вероятных видов с процентом уверенности
- Автоматическое определение типа входного тензора (float / uint8) и корректная предобработка
- Запрос разрешений на камеру в рантайме
- Безопасная работа с файлами через FileProvider

---

##  Используемые технологии

| Компонент          | Описание |
|-------------------|----------|
| Язык              | Kotlin |
| Архитектура UI    | ConstraintLayout + стандартные View |
| Нейросеть         | TensorFlow Lite (MobileNetV2, iNaturalist Plants – 2101 вид) |
| Съёмка            | `ActivityResultContracts.TakePicture` |
| Доступ к файлам   | `FileProvider` (cache-path) |
| Минимальная версия| Android 7.0 (API 24) |
| Целевая версия    | Android 14 (API 34) |
